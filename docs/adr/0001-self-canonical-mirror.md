# Mirror pages are self-canonical, not canonical to tribelt.nl

Every Mirror Page declares its own URL on tribelt.jorisjonkers.dev as canonical. Pointing canonicals at the Official Page would protect Tribelt's rankings completely, but search engines would then mostly not index the mirror, and the search channel, which is half of what this project measures, would read as zero. To limit competition with the official site we differentiate instead: page text is adapted rather than copied, titles differ, and every page links prominently to its Official Page. Tribelt has been asked to confirm this trade-off.

## Consequences

- The mirror may appear for Tribelt brand queries. Watch Search Performance for brand terms after each Content Release.
- Switching to tribelt.nl canonicals later is a one-line change but resets whatever the mirror has earned in search, so treat it as ending the search experiment.
